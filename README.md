# Deal Rescue para Codex

Una habilidad de Despega Creativo para decidir cuándo y cómo dar seguimiento a oportunidades comerciales B2B en agencias, productoras y otras empresas creativas de Latinoamérica.

## Qué hace

Lee el contexto de una oportunidad, identifica si conviene contactar ahora y recomienda uno de los siete movimientos del Sistema de 7 Seguimientos™. Si toca escribir, entrega un mensaje breve que tú revisas y envías. No se conecta a un CRM ni envía mensajes por tu cuenta.

## Instalación en Codex

Abre Codex y pega este mensaje:

> Usa $skill-installer para instalar la habilidad Deal Rescue desde https://github.com/santiagocortescalle/deal-rescue-skill/tree/main/deal-rescue. Avísame cuando esté disponible.

Si la habilidad no aparece después de instalarse, reinicia Codex. Compartir el enlace no instala la habilidad automáticamente. Cuando publiquemos una actualización, vuelve a instalarla para recibir los cambios.

## Primer uso

En Codex, escribe `$deal-rescue` y pega el último intercambio con tu prospecto. Por ejemplo:

> $deal-rescue Envié una propuesta de identidad de marca el lunes. El cliente dijo que su comité la revisaría el viernes. Hoy es miércoles. ¿Qué hago?

Incluye, si los tienes: servicio o proyecto, palabras exactas del prospecto, acuerdos y fechas, mensajes ya enviados y canal de comunicación. Puedes ocultar datos personales antes de pegar una conversación.
